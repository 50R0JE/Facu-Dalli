# Reel · escáner de código de barras

Reel 1080×1920, 30 fps, sin audio, ~18 s: tocar el escáner, apuntar al código,
ver calorías y macros por gramo (con fichas de datos que salen del teléfono) y
cómo se suma al día. Usa el motor de `../reel-atleta` y `../reel-video-ejercicio`.

```bash
python3 reel.py salida.mp4 grabacion-del-escaner.mp4
```
