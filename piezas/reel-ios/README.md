# Reel · Llegamos a iPhone

Reel 1080×1920, 30 fps, sin audio, ~21 s: gancho «¿Tenés iPhone?», la fecha en neón que
rueda día por día hasta el lanzamiento, tres funciones de la app (rutina, series, escáner)
y cierre con la firma y «Llegamos el 28.09».

```bash
python3 reel.py salida.mp4 28.09     # la fecha es el segundo argumento
```
