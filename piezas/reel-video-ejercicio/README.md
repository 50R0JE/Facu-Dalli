# Reel · video de cada ejercicio

Reel 1080×1920, 30 fps, sin audio, ~21 s. Muestra que el coach pega el link de un video
en cada ejercicio (pantalla del coach simulada, igual al editor de `app/screens/coach/rutinas.js`)
y que el atleta lo abre desde su rutina con «Ver video del ejercicio» y sigue anotando.

Usa el motor de `../reel-atleta/reel.py` (fondos, teléfono, textos, barridos).

```bash
python3 reel.py salida.mp4 grabacion-del-panel.mp4
```

El usuario del Short de YouTube y el nombre del coach se difuminan en el render.
